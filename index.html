Token Generator

این ابزار برای تولید توکن خودرو و متادیتای آن طراحی شده است. پس از وارد کردن مشخصات، تصویر و شرایط فنی، یک فایل JSON آماده دانلود می‌شود.

چه چیزی تولید می‌شود؟

  • شناسه یکتا برای هر توکن خودرو
  • نام، توضیحات و ویژگی‌های قابل فیلتر
  • تصویر اصلی و داده‌های تصویری آماده برای متادیتا
  • فایل JSON قابل دانلود برای استفاده در بازارهای دیجیتال

مهم‌ترین فیلدها

  • سازنده، مدل، تیپ و سال ساخت
  • کارکرد، رنگ، شهر و وضعیت کلی خودرو
  • وضعیت موتور، گیربکس، لاستیک و تصادف
  • قیمت، نوع فروش و قابلیت مذاکره

ERC-721

در استاندارد ERC-721، هر توکن می‌تواند به یک فایل متادیتا اشاره کند. این فایل معمولاً شامل این بخش‌هاست:

  • name: نام توکن، مانند برند، مدل و نسخه خودرو
  • description: توضیح کامل درباره خودرو و شرایط فروش
  • image: تصویر خودرو به‌صورت داده یا آدرس قابل‌استفاده
  • attributes: اطلاعات قابل‌فیلتر مانند رنگ، سال، کارکرد و قیمت

این پروژه فقط فایل متادیتا را آماده می‌کند؛ اتصال کیف‌پول، ذخیره‌سازی دائمی و مینت واقعی روی شبکه باید به‌صورت جداگانه انجام شود.
