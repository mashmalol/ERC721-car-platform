این فرم برای تبدیل یک خودرو به یک رکورد قابل بررسی طراحی شده است. اطلاعات را از روی سند، بیمه‌نامه و بازدید فنی وارد کنید؛ حدس‌زدن، کیفیت آگهی را پایین می‌آورد.

کنترل‌های ضروری

  • هویت: سازنده، مدل، تیپ، سال، شهر و رنگ
  • وضعیت: موتور، گیربکس، لاستیک، تصادف و قطعات رنگ‌شده
  • معامله: قیمت، نوع فروش و امکان مذاکره
  • خروجی: تصویر، توضیحات و متادیتای JSON قابل دانلود

برای اطلاعات دقیق‌تر

  • تصویر: عکس روشن و واقعی از جلو، عقب، کابین و بخش‌های آسیب‌دیده اضافه کنید.
  • فنی: وضعیت موتور، گیربکس و لاستیک را بر اساس بازدید یا گزارش کارشناسی وارد کنید.
  • بدنه: قطعات رنگ‌شده و تصادف را دقیق بنویسید؛ «بدون رنگ» را فقط در صورت اطمینان انتخاب کنید.
  • امکانات: آپشن‌ها را با جداکننده بنویسید، مثل «سانروف، دوربین، سنسور پارک».
  • توضیحات: ایرادهای موجود، زمان آخرین سرویس و هر نکته‌ای که خریدار باید بداند را اضافه کنید.

خروجی چه دارد؟

فایل JSON شامل شناسه لیست، قیمت، تصویر، مشخصات خودرو، وضعیت فنی و شرایط معامله است. این فایل برای آرشیو، بررسی یا اتصال به سیستم‌های بعدی آماده می‌شود.

ERC-721 و متادیتای JSON

در استاندارد ERC-721، هر توکن می‌تواند به یک فایل متادیتا اشاره کند. این فایل معمولاً شامل چهار بخش اصلی است:

  • name: نام قابل نمایش توکن، مانند سازنده، مدل و تیپ خودرو
  • description: توضیحات کامل درباره وضعیت و شرایط خودرو
  • image: تصویر خودرو با آدرس یا داده تصویری قابل خواندن توسط کیف‌پول و مارکت
  • attributes: ویژگی‌های قابل فیلتر مانند سال، کارکرد، رنگ، سوخت و قیمت

شناسه توکن باید یکتا باشد و آدرس متادیتا باید تا حد ممکن پایدار بماند. این پروژه فایل JSON را آماده و قابل دانلود می‌کند؛ اتصال کیف‌پول، ذخیره‌سازی دائمی و مینت واقعی روی شبکه هنوز جداگانه باید اضافه شود.

اطلاعات تماس در متادیتای عمومی ذخیره نمی‌شود؛ آن را فقط در کانال امن معامله نگه دارید.
