# پلتفرم خودرو

این پروژه یک نمونه‌ی وب‌سایت تک‌صفحه‌ای برای لیست‌کردن خودروها و ساخت متادیتای دیجیتال است. این سایت برای دلالان و فروشنده‌های خودرو طراحی شده که با مفاهیم دیجیتال، NFT و داده‌های ساختاریافته کار می‌کنند. هدف اصلی، تبدیل یک لیست خودرو به یک بسته‌ی اطلاعاتی آماده‌ی استفاده در محیط‌های دیجیتال و آینده‌ی بلاک‌چین است.

## معرفی کوتاه

این صفحه یک تجربه‌ی بصری شبیه به محیط‌های آینده‌نگر دارد. کاربر می‌تواند:
- تصویر خودرو را آپلود کند
- جزئیات مهم خودرو را وارد کند
- تصویر را به داده‌ی Base64 تبدیل کند
- یک فایل JSON از متادیتا ایجاد و دانلود کند
- نمونه‌هایی از خودروهای دیجیتال را در یک مودال مشاهده کند

## مخاطب هدف

این ابزار برای دلالان، فروشنده‌های خودرو و افراد تکنولوژی‌دوست طراحی شده است که می‌خواهند روند فروش خودرو را از حالت سنتی به یک مدل دیجیتال‌تر و قابل مدیریت‌تر منتقل کنند.

## ERC-721 چیست؟

ERC-721 یک استاندارد روی شبکه‌ی اتریوم است که برای ساخت توکن‌های غیرقابل تعویض به کار می‌رود. هر توکن ERC-721 منحصر به فرد است و می‌تواند به عنوان یک دارایی دیجیتال، یک سند مالکیت، یا یک آیتم خاص در یک پلتفرم نمایش داده شود.

برای دلالان خودرو، این مفهوم می‌تواند به این شکل معنی‌دار باشد:
- هر خودرو می‌تواند به‌صورت یک دارایی دیجیتال ثبت شود
- اطلاعات آن در قالب متادیتا نگهداری شود
- در آینده می‌توان آن را در پلتفرم‌های NFT یا سیستم‌های مالکیت دیجیتال استفاده کرد

## امکانات پروژه

- فرم کامل برای وارد کردن اطلاعات خودرو
- آپلود تصویر خودرو
- تبدیل تصویر به Base64 با قالب‌بندی سفارشی
- ساخت متادیتای JSON با داده‌های خودرو
- دانلود فایل JSON
- پنجره‌ی اطلاعات برای توضیح مفهوم ERC-721 و کاربرد متادیتا
- نمایش نمونه‌ی خودروهای دیجیتال در مودال

## ساختار فایل‌ها

- [index.html](index.html): ساختار صفحه، استایل‌ها و محتوای UI
- [script.js](script.js): منطق فرانت‌اند، پردازش تصویر، ساخت متادیتا و کنترل مودال‌ها

## راه‌اندازی در لوکال‌هاست

این پروژه یک سایت استاتیک است و نیازی به نصب وابستگی ندارد.

### روش ۱: استفاده از Python

اگر Python روی سیستم شما نصب است، این دستور را اجرا کنید:

```bash
cd /home/mash/programming/carplatform
python3 -m http.server 8000
```

سپس در مرورگر، این آدرس را باز کنید:

```text
http://localhost:8000/
```

### روش ۲: استفاده از Node.js

اگر Node.js دارید، می‌توانید از سرور ساده‌ی زیر استفاده کنید:

```bash
cd /home/mash/programming/carplatform
npx serve .
```

سپس این آدرس را باز کنید:

```text
http://localhost:3000/
```

## نحوه‌ی استفاده

1. سرور محلی را روشن کنید

6. فایل JSON را دانلود کنید
7. برای آشنایی با مفهوم ERC-721 و کاربرد این داده‌ها، روی دکمه‌ی دایره‌ای پایین صفحه کلیک کنید
